### 2.4 Поведение при недоступном соседе

**Как пользователь, я хочу получить внятный ответ, даже когда часть системы
не работает, чтобы не смотреть минуту на пустой экран.**

Условия приёмки:
- Если сервис клиентов не отвечает, сервис заказов возвращает код 503
  не дольше чем за три секунды.
- Есть тест на этот случай.
- Ограничение времени ожидания задаётся настройкой, а не числом в коде.
