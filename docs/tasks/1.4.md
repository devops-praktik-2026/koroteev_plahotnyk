### 1.4 Список заказов клиента

**Как менеджер, я хочу видеть все заказы одного клиента, чтобы понимать
историю его покупок.**

Условия приёмки:
- Запрос со ссылкой на клиента возвращает только его заказы.
- У клиента без заказов возвращается пустой список и код 200, а не ошибка.
- Есть возможность ограничить размер выдачи.

Статус: локальная заготовка; карточку GitHub ещё нужно создать.
