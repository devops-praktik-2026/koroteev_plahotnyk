### 2.5 Описание стенда кодом

**Как пара, мы хотим описать стенд текстом, чтобы его можно было удалить
и создать заново в том же виде.**

Условия приёмки:
- Одна команда создаёт стенд, другая полностью его удаляет.
- Повторное создание даёт то же самое состояние.
- Файл состояния не попадает в репозиторий.
- В описании изменения объяснено, что произошло, когда оба участника пары
  применили описание одновременно.

Статус: локальная заготовка; карточку GitHub ещё нужно создать.
